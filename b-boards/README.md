# Plano B: os quadros aprovados

Os quadros de B5 (Rolar dados), B3 (aviso "No escuro"), B2 (mapa fora do combate) e B6 (zonas de magia), desenhados no sistema "Ficha de papel" e revisados. Cada PNG é um quadro, a 390 px (celular) ou 1280 px (computador). Os quadros de estados reúnem os casos de cada item.

- `B5-*`: o botão "Dados" no cabeçalho da sessão, a folha (celular) e o diálogo (computador), a rolagem secreta do mestre, os estados.
- `B3-*`: o aviso para o mestre, a lista de quem está no escuro, "Acender luz", os estados.
- `B2-*`: mover token (arrastar, segurar e arrastar no celular, "Mover" com quadrados), selecionar vários e movê-los juntos, "Pôr o grupo no mapa", a camada "Não dá para passar", quem entra no combate, os estados.
- `B6-*`: as zonas no mapa e no painel do combate (mestre e jogador), o teste de resistência do jogador, "Mover o Raio Lunar", os estados.

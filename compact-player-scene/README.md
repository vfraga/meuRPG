# Cena do jogador e painel "Ficha" (feat/compact-player-scene)

Capturas do app real (a pilha local: API, banco e o app compilado), nos quatro larguras (320, 390, 768, 1280), claro e escuro. Nome: `<tema>-<largura>-<tela>.png`.

| Tela | O que mostra |
| --- | --- |
| `cena-sem-imagem` | A cena aberta sem imagem à mostra: o palco, "O que você pode fazer", o mapa, as dobras |
| `cena-imagens-deixadas` | O mesmo com duas imagens deixadas pelo mestre (celular: dobra de uma linha) |
| `cena-imagens-deixadas-aberta` | Celular: a dobra aberta |
| `cena-com-imagem` | Com uma imagem à mostra: a imagem primeiro (celular) ou ao lado da cena (1280) |
| `cena-rolagens-aberta` | "Rolagens da mesa" aberta |
| `ficha-conjurador` | "Ficha" de Pensantus (mago): painel (celular), aba do trilho (1280), sob a cena (768) |
| `ficha-guerreiro` | "Ficha" de Toren (guerreiro) |
| `cena-com-conversa` | 1280: o trilho em "Conversa" |
| `*-tela` | Celular: só a tela, sem rolar (a barra fixa embaixo) |

As imagens de página inteira (`fullPage`) mostram a barra do app no meio quando a página rola: é um efeito da captura, não da tela.

# Free dice roller (B5): harness captures

**These are HARNESS CAPTURES, not the live stack** (no Docker daemon or CockroachDB was available). The real components (`app-free-dice-sheet` opened through `openFreeDice` as a bottom sheet / dialog, `app-free-roll-card`, `app-free-roll-log`, `app-session-header`, `app-roll-overlay` fed by `freeRollShow`, and the real `FreeDiceState`) were rendered in Chromium with fake data: a fake `list`/`roll` client answers the rolls, nothing ran against the server, the stream or the database. The surrounding page (top bar, "Mapa" placeholder) is a stand-in. Rendered from commit `06e18652a` (branch `feat/free-dice-roller`) by a throwaway harness in a detached worktree, never committed to the feature branch. Fonts are the app's self-hosted ones.

Matrix: widths 390 (bottom sheet) and 1280 (440 px dialog), light and dark (`prefers-color-scheme`), device scale 1. File name: `dados-<state>-<role>-<width>-<theme>.png` (role `jogadora` = player, `mestre` = master). Viewport shots (the table overlay and the header are viewport / element shots).

States: `formulario` (player and master, 2d6 + 3), `formulario-segredo` (master, 1d20 + Vantagem + "Só eu"), `resultado` (2d6 + 3 = 11 (4, 4); player and master), `vantagem` ("descartado"), `natural-20`, `natural-1`, `vinte-dados` (wrapping), `d100`, `resultado-segredo` (master, "Só você"), `dados-fisicos` (note + "Rolar no app"), `lista-vazia`, `lista-carregando`, `lista-falhou`, `rolando` ("Rolando…" + "?" dice), `recusada` (rate limit, "em 3 segundos"), `sem-conexao` (button off + "Reconectando… Não dá para rolar sem conexão."), `cabecalho-normal|rolando|sem-conexao` (390), `registro` (1280, "Registro da sessão"; the master's list has a "Só você" line, the player's does not), `mesa-brisa-rolou` (table overlay, "Rolagem livre · 2d6 + 3").

## Defects against the board

1. **High, 390 x 844 (also a smaller phone): the primary button is below the fold in the master's form and in every state with a footer notice** (`dados-formulario-mestre-390-*`, `formulario-segredo`, `dados-fisicos`, `sem-conexao`, `recusada`). Measured: the bottom-sheet container is 760 px high (`styles.scss:266`, `.mr-sheet-tall .mat-bottom-sheet-container { max-height: calc(100dvh - 84px) }`) but the frame inside may be 804 px (`shared/sheet/sheet-frame/sheet-frame.scss:12-14`, `&--phone { max-height: calc(100dvh - 40px) }`), so the container scrolls by 44-60 px and the footer ("Rolar ..." at y 840-888 in an 844 px viewport) is cut off and the body scrolls inside a second scroller. The footer is meant to "never scroll away" (`free-dice-sheet.scss:220`). Fix: give this sheet a `panelClass` whose container `max-height` equals the frame's (`calc(100dvh - 40px)`), or set the frame's phone `max-height` to `calc(100dvh - 84px)` when the sheet is tall (one scroller, the footer fixed).
2. **Low, 1280 and 390: the "de novo" button wraps to two lines** for long labels ("Rolar 1d20 + 5 com vantagem de novo", "Rolar 2d6 + 3 de novo, para a mesa"); the board shows one line. Cause: `.foot__pair` splits the width with "Mudar dados" (`free-dice-sheet.scss:227-233`). Fix: let the primary take `flex: 1 1 auto` / stack the pair on 390 when the label is long.
3. **Low, overlay:** the total in "Brisa rolou" is a small 20 px sans line (`shared/roll-overlay/roll-overlay.scss:242-246`) where the board shows a large display-face "11" under the dice (B5-06 state 12). Fix: a larger display-face size for `.result__line` when the roll is a free roll (or a `result--big` modifier).
4. **Low, "Registro da sessão":** the board splits the log into "Jogadoras e mesa" and "O mestre lê também" and adds the line "A rolagem secreta não existe para os jogadores..."; the component renders one newest-first list with the "Só você" badge (`pages/live-session/free-dice/free-roll-log.ts`, template). The badge keeps the meaning, so this is a visual deviation only.
5. **Low, copy:** the rolling card says "Você rola 1d20…" where the board says "Brisa rola 2d6 + 3…" (name + formula) (`free-dice-sheet.html`, `card--rolling`).

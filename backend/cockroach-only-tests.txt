# The backend tests that need CockroachDB itself, and why.
#
# The go-db job runs the tests on PostgreSQL in a preflight and on CockroachDB in a train PR, on main and in the nightly hunt
# (docs/ci.md). The preflight skips the tests listed here, by name, and says so in its log; the CockroachDB runs run them.
# .github/scripts/cockroach-only.sh checks the list:
#   check-names   every entry is a test that exists in its package, and no other package has a test of the same name
#   check-list    every listed test fails on PostgreSQL (so a test that stops needing CockroachDB must leave the list)
# A test outside the list that needs CockroachDB fails in the PostgreSQL run.
#
# One entry per line: <package directory from backend/> <top-level test name> <why it needs CockroachDB>
internal/campaigns TestInvitesAreDeletedByTheDatabase row-level TTL of campaign_invites, read with SHOW CREATE TABLE
internal/campaigns TestQ24_PendingMembershipExpiresAfter30Days row-level TTL of campaign_members, read from the table options
internal/characters TestOrphanedPlayerCharactersAreDeletedByTheDatabase row-level TTL of characters, read from the table options
internal/identity TestRowLevelTTL row-level TTL of auth_sessions and oidc_login_states, read with SHOW CREATE TABLE
internal/play TestRosterReadInsideTxIsRetriedOn40001 a 40001 injected into a read (inject_retry_errors_enabled)
internal/play TestRosterReadInsideTxIsRetriedOnRealConflict a conflict made by a HIGH priority transaction (SET TRANSACTION PRIORITY), and UPSERT
internal/platform/dbtest TestSchemaDDLOrdersTablesAfterTheirReferences the schema copy replays SHOW CREATE (CockroachDB's way of making a test database)
internal/platform/dbtest TestSchemaDDLRefusesACycle the schema copy replays SHOW CREATE (CockroachDB's way of making a test database)
